
# Kopi Senja — Java Coffee Ordering System

## Project Overview

Kopi Senja is a simple coffee ordering system developed using Java for Object-Oriented Programming Assignment 1 at Management and Science University (MSU).

The system allows customers to select drinks, enter quantities, check availability, and receive a receipt with the total payment, membership discount, and loyalty points.

## OOP Concepts Implemented

- Classes and objects
- Encapsulation using private attributes
- Default and parameterized constructors
- Getter and setter methods
- Methods for calculations and availability checks
- Selection structures (`if/else` and `switch`)
- Looping structure (`do-while`)

## Java Files

- `Drink.java` — Manages drink information, pricing, and availability.
- `Customer.java` — Manages customer details, membership discounts, and loyalty points.
- `KopiSenjaMain.java` — Runs the interactive ordering system.

## How to Run

1. Ensure Java JDK is installed.
2. Open a terminal in the project folder.
3. Compile the files:

   `javac Drink.java Customer.java KopiSenjaMain.java`

4. Run the main class:

   `java KopiSenjaMain`
